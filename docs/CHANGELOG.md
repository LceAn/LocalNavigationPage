# 更新日志 (CHANGELOG)

## [1.5.1] - 2026-08-30

### 🎨 分组展示重做

- 分组改为 Cootab 风格图标磁贴：图标在上、名称居中（最多两行）、强调色小标签在下
- 分组容器变为半透明玻璃簇面板；磁贴网格 auto-fit 均分整行
- 项目身份元素完整保留：在线/离线状态点、内网/公网路线角标、多地址菜单、主色体系
- 「默认隐藏分组、点击展开」的交互保持不变

### 🐛 问题修复

- 修复多标签页同时打开时设置互相覆盖的竞态（写入前重读最新数据 + 监听 storage 同步缓存）
- 修复内网链接缩略图向外部截图服务发起注定失败的请求，现回退为首字母 + favicon
- 修复夜间模式刷新时闪白（首帧前应用主题）
- 修复添加链接弹窗地址区默认为空，需手动点击「添加地址」的问题（现预置一行）
- 修复 validate.mjs 在 Windows 上全部误报「资源路径越界」的问题（跨平台路径判断）

### ⚡ 性能与体验

- preconnect/dns-prefetch 缩略图与 favicon 服务
- 统一静态资源缓存参数为版本号
- 无障碍：视图标签暴露选中状态（aria-pressed）、分组头键盘焦点环
- 新增 `npm run serve` 零依赖静态服务器
- validate 支持 `LNP_ALLOW_PRIVATE_LINKS=1` 本地豁免（CI 保持严格）
- 字体与图标本地化（Inter latin 子集 + Remixicon，共约 200KB），断网或纯内网环境界面完整可用

## [1.4.0] - 2026-06-19

### ✨ 2026 现代化焕新

#### 🎨 视觉
- 设计令牌升级为现代 CSS：主色 `oklch()`、派生色 `color-mix()`，新增第三色（青）
- 修复深色模式阴影（原 4 档 alpha 相同，卡片无层次），改为递进深度
- 标题改用流式字号 `clamp()`，修复字重未加载导致的标题粗细回退
- 链接卡片 hover 上浮更明显、补内高光，玻璃质感更利落
- 圆角令牌统一（消除 `18px` 硬编码），新增 `--rounded-2xl`、`--ease-out-expo`

#### ⚙️ 技术与可访问性
- 新增全局 `prefers-reduced-motion` 守护
- 删除约 128KB 死代码（jQuery / Bootstrap）与 macOS 资源叉文件
- 修正 `theme-color` 与实际主色不符，并补深色模式变体
- 清理 styles.css 中与 search_input.css 冲突的重复搜索框规则
- 全局版本号对齐到 1.4.0

#### 🚀 性能与 PWA
- 字体改用可变字体区间 `400..800`，减重且覆盖此前缺失字重
- 新增 `preconnect`（Google Fonts / jsdelivr）
- 脚本加 `defer`；首页缩略图改 `<img loading="lazy">`
- 新增 PWA 基础面：Web App Manifest + 内联 SVG favicon + apple-touch-icon

## [1.1.0] - 2026-03-18

### ✨ 新增功能

#### 多 URL 支持
- 一个网站可以配置多个 URL 地址
- 支持设置 URL 标签（如：本地网络、Tailscale、向日葵）
- 支持设置 URL 优先级
- 卡片右上角显示下拉按钮，可快速选择不同地址
- 设置界面中显示多 URL 信息（+N 个地址）

#### 外观与显示设置合并
- 将原来的"外观"和"显示设置"标签页合并为"外观与显示"
- 简化设置导航，从 6 个标签页减少到 5 个

#### 天气功能增强
- 支持配置多个城市显示天气
- 多城市时在天气后显示城市名称列表（如：shanghai / beijing / guangzhou）
- 单个城市时不显示城市名称，保持简洁

### 🔧 功能优化

#### 设置菜单优化
- 合并相关设置项，使界面更加简洁
- 优化设置分类逻辑，将时间、日期、天气等显示相关设置归为一类

#### 数据格式兼容
- 新的多 URL 格式使用 `urls` 数组存储
- 保持与旧格式 `url` 字段的兼容性
- 单个 URL 时自动使用旧格式，多个 URL 时使用新格式

### 📝 数据结构

#### 多 URL 数据格式
```json
{
    "links": [
        {
            "ID": 1,
            "name": "群晖 NAS",
            "urls": [
                {
                    "address": "https://192.168.2.100:5000",
                    "label": "本地网络",
                    "priority": 1
                },
                {
                    "address": "https://100.64.0.5:5000",
                    "label": "Tailscale",
                    "priority": 2
                }
            ],
            "category": "云服务",
            "thumbnail": "..."
        }
    ]
}
```

#### 单 URL 数据格式（兼容）
```json
{
    "links": [
        {
            "ID": 1,
            "name": "群晖 NAS",
            "url": "https://192.168.2.100:5000",
            "category": "云服务",
            "thumbnail": "..."
        }
    ]
}
```

### 🐛 Bug 修复

- 修复了设置界面存储信息显示不准确的问题
- 修复了天气功能在某些情况下的显示问题
