### 🖱 修复：卡片 ⋯ 要右键才开、菜单弹在别处

**左键点不准就变成打开地址**
- ⋯ 按钮只有 30px，点在它外侧 1–2px 就落到卡片整体的「打开地址」热区上；右键能出菜单只是因为它走的是另一条 `contextmenu` 路径，看起来像「必须右键」

- 卡片在屏幕底部时按视口下缘收起，不会被裁掉；窄屏（390px）同样贴着卡片左上角展开
- 菜单现在压在卡片上，玻璃底从 60% 提到 97%，否则下面的卡片标题会透上来（与网络气泡的处理保持一致）

## [1.43.1] - 2026-11-18

### 🌙 修复：夜间模式下时间 / 日期 / 天气背后出现纯黑底块

- 症状：深色模式下首页顶部的三块信息（时间、日期、天气）各自带一块近黑的矩形底，和液体玻璃的渐变背景格格不入；浅色模式正常
- 根因：`styles.css` 里 `.dark-mode.home-glass-enabled .datetime-chip { background-color: rgba(15,23,42,.72) }` 有三个类，权重 (0,3,0)；而 `navigation.css` 里 liquid 皮肤写的 `body.liquid-home .datetime-chip { background: transparent }` 只有 (0,2,1)，压不过它 —— 于是深色 + 玻璃模式下被重新刷成 `#0f172a` 的 72% 实心块
- 修法：在 `navigation.css` 用 `body.liquid-home .datetime-display > .datetime-chip`（(0,3,1)）显式归零背景、描边、阴影与 `backdrop-filter`，并额外覆盖 `.dark-mode` / `.home-glass-enabled` 两种组合，保证四种状态一致
- 浅色模式此前就是透明（两处同权重、navigation.css 后加载），本次行为不变
- 版本号 1.43.1

- 右栏布局为了让数字竖排藏的冒号、撑开的秒数间距，在抽屉里一并还原成 `18:35:20`

### 🌧 雨雪按强度分级 + 粒子强度真正生效

**雨雪细分**（WWO 编码本身带强度，直接映射）
| 大类 | 细分 | 编码 |
|---|---|---|
| 雨 | 毛毛雨 / 小雨 / 中雨 / 大雨 / 暴雨 | 263·266 / 176·293·296 / 299·302 / 305·308 / 359 |
| 雷雨 | 局部雷雨 / 雷阵雨 / 强雷暴 | 200·386 / 389 / 389+描述含 heavy |
| 雪 | 小雪 / 中雪 / 大雪 / 暴雪 / 雨夹雪 | 179·323 / 329·332 / 227·335·338 / 230 / 182·317·320 |

- 每档有独立的粒子数量、雨丝长度与粗细、透明度、倾角、下落速度；暴雨以上还会整体压暗并起水汽（`--fx-veil`），雷暴的闪电间隔随档位从 13 秒缩到 5 秒
- 叠加「强度」后视觉差异：毛毛雨 轻 ≈ 2k 墨迹像素，暴雨 标准 ≈ 31k，强雷暴 ≈ 23k（1440×900 实测）

- 保持与旧格式 `url` 字段的兼容性
- 单个 URL 时自动使用旧格式，多个 URL 时使用新格式

                    "priority": 1
                },
                {
